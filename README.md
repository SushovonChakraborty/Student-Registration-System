# 🎓 Student Registration System

## 📌 Overview

This project is a **Student Registration System** built using HTML, CSS, and JavaScript.
It allows users to register students, view records, edit existing details, and delete records.
All student data is stored in **localStorage**, so the information remains even after refreshing the page.

---

## 🚀 Features

* 📄 **Add New Student** – Register student with Name, ID, Email, and Contact Number.
* ✏️ **Edit Records** – Update existing student details.
* ❌ **Delete Records** – Remove unwanted entries.
* 💾 **LocalStorage Support** – Data persists after page refresh.
* ✅ **Input Validation** –

  * Student Name → only alphabets allowed
  * Student ID → only numbers allowed
  * Email → must be in valid format
  * Contact Number → minimum 10 digits, only numbers
* 📱 **Responsive Design** – Works smoothly on **mobile, tablet, and desktop**.
* 📜 **Dynamic Scrollbar** – Vertical scrollbar appears automatically when records overflow.

---

## 🛠️ Technologies Used

* **HTML5** → Structure of the system
* **CSS3** → Styling and responsive design
* **JavaScript (ES6)** → Functionality (CRUD operations + validation + localStorage)

## ⚡ How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Double-click `index.html` to open in your browser.
4. Start registering students! 🎉
